### Creating SSH key

configure your username and email

* Open Git bash or your terminal of choice.  
* Use these commands:  

```
git config --global user.name "John Doe"  
git config --global user.email johndoe@example.com
```

Generate SSH keys:

* open Git bash or your terminal of choice. 
* input this command:   

```
ssh-keygen -t rsa -b 2048 
```

* you should see a prompt like this:

```
Enter file in which to save the key (C:\Users\David/.ssh/id_rsa)
```

* If you use this path, the public key will be in the file below:

```
C:\Users\David/.ssh/id_rsa.pub
```

* You can open that file in a text editor, or use this command:

```
cat C:\Users\David/.ssh/id_rsa.pub
```

* copy the complete contents of that file for the next step

### Adding SSH keys to Gitlab

Add SSH keys to Gitlab

* [Log in to Gitlab](https://gitlab.cs.unh.edu/users/sign_in);   
* Go to User settings
* Go to SSH keys  
* Paste the entire contents of the .pub file from above
