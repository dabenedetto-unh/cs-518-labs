# Regression testing

## Installing dependencies from requirements.txt

To install dependencies from requirements.txt, use this command (execute in the directory with requirements.txt):

```
pip install -r requirements.txt
```

* Note: you may need to use "python -m pip" or "python3 -m pip" instead of just "pip"

## Installing local project

* you need to install your project locally so that you can import your modules in your tests
* In your project root, there is a file "pyproject.toml" 
    - inspect this file
* open a terminal at the root and install with this command (don't miss the dot):

```
pip install -e .
```

## Running your tests in VS Code

* open a py file to enable python context
* Click testing icon in left sidebar (looks like a lab flask)
* Click "configure python tests"
* choose unittest
* select your 'tests' directory
* tests follow test_* pattern

More information:

* https://code.visualstudio.com/docs/debugtest/testing

## running individual tests

* Now you can run individual tests using the testing panel, or clicking the play icons in your code
